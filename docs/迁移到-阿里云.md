# 迁到阿里云（推荐，替代 Zeabur / Railway）

Zeabur [停运](https://zeabur.com/zh-CN/blogs/migrate-from-zeabur)后，本仓库推荐：

| 能力 | 方案 | 说明 |
|------|------|------|
| 定时推送触发 | **函数计算 FC 定时触发器** | 按次计费，北京时区，见 [`aliyun-fc-trigger/`](../aliyun-fc-trigger/) |
| 情报 Web/API | **轻量应用服务器** 或 FC 自定义容器 | 国内访问稳，企微里直接打开 |
| 对象存储 | 已有 **OSS** | 不动 |
| 推送执行 | 已有 **GitHub Actions** | 不动 |
| 公众号 RSS | 已有 **SupSub** | 一般不必再迁旧 WeWe |

---

## 一、FC：定时触发（必做，保推送）

按 [`aliyun-fc-trigger/README.md`](../aliyun-fc-trigger/README.md) 创建函数 + 6 个定时触发器。

验证：测试事件 `{"mode":"timed"}` → Actions 跑起来 → **停掉 Zeabur/Railway 旧触发器**。

## 二、情报应用 `intel-app`（轻量应用服务器，推荐）

比 FC 自定义容器省心，适合 FastAPI 常驻：

1. 阿里云买一台 **轻量应用服务器**（例如 2 核 2G，系统 Ubuntu 22.04，地域靠近 OSS）  
2. 安全组放行 **80/443**（及临时 22）  
3. SSH 登录后：

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
sudo usermod -aG docker $USER   # 重新登录后生效
git clone https://github.com/qinxiaoxia/eason727.git
cd eason727/intel-app
```

4. 写环境文件（勿提交）：

```bash
cat > .env <<'EOF'
OSS_PUBLIC_BASE_URL=https://eason727.oss-cn-beijing.aliyuncs.com
OSS_ACCESS_KEY_ID=你的AK
OSS_ACCESS_KEY_SECRET=你的SK
OSS_BUCKET=eason727
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
INTEL_WEB_PASSWORD=你的口令
INTEL_API_TOKEN=你的随机Token
INTEL_DATA_DIR=/data
PORT=8080
EOF
```

5. 启动：

```bash
sudo mkdir -p /var/lib/intel-app && sudo chown "$USER" /var/lib/intel-app
docker build -t intel-app .
docker run -d --name intel-app --restart unless-stopped \
  -p 80:8080 \
  --env-file .env \
  -v /var/lib/intel-app:/data \
  intel-app
```

6. 浏览器打开 `http://服务器公网IP/`，口令登录。  
7. （建议）在轻量控制台绑域名 + 免费证书，或前面加 Nginx/Caddy 做 HTTPS。  
8. 企微知识库入口改成该域名。

### 备选：FC 自定义容器跑 intel-app

把本仓库 `intel-app/Dockerfile` 推到阿里云容器镜像服务 ACR，再在 FC 创建「自定义容器」HTTP 函数，环境变量同上。适合已有 FC 经验时使用；冷启动略慢。
