# RSS → 企业微信推送（需求版）

将 RSS 订阅（WeWe RSS + 网安站点）自动推送到企业微信群，支持分类、实时/定时推送。

> 新手请先看 **[入门指南.md](./入门指南.md)**。

## 功能

| 功能 | 说明 |
|------|------|
| **多源** | 微信公众号（WeWe RSS）+ 7 个网安 RSS |
| **分类** | 6 类：监管机构预警、漏洞信息、重大安全事件、网安新闻资讯、网安赛事资讯、其他资讯 |
| **规则分类** | 监管机构预警：公众号+标题规则（Phase 1 已实现） |
| **大模型分类** | 其余类别（Phase 2 待接入） |
| **轮巡实时** | 监管机构预警、重大安全事件 → 北京 **6、18** 整点 + 定时档同跑时推送 |
| **LLM** | 分类/翻译用 `qwen-turbo`；IOC 提取用 `qwen3.7-plus`（见 GitHub Secrets） |
| **定时推送** | 漏洞信息等定时六类 → 北京 **9:30、12:00、15:30、17:30** 汇总推送 |
| **推送格式** | 【信息类型】【标题】【时间】【链接】 |
| **去重** | SQLite 记录已推送，避免重复 |
| **噪声过滤** | 规则剔除 + 公众号 turbo 语义复核（须属网安/AI 八类之一）；见 `exclusion_reason` |
| **监管预警 @** | 推送「监管机构预警」时 @ `wangxuyang`、`qinxiaoxia`（企微 userid，可改 Secret） |

## 文件说明

| 文件 | 说明 |
|------|------|
| `main.py` | 主程序 |
| `classifier.py` | 分类器（规则 + 大模型占位） |
| `config.py` | 配置（需自行创建） |
| `config.example.py` | 配置示例 |
| `rss_push.db` | 文章与推送记录（自动生成） |

## 运行

```bash
pip3 install -r requirements.txt
python3 main.py
```
