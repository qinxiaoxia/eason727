# RSS → 企业微信推送（需求版）

将 RSS 订阅（WeWe RSS + 网安站点）自动推送到企业微信群，支持分类、实时/定时推送。

> 新手请先看 **[入门指南.md](./入门指南.md)**。

## 功能

| 功能 | 说明 |
|------|------|
| **多源** | 微信公众号（WeWe RSS）+ 7 个网安 RSS |
| **分类** | 6 类：监管机构预警、漏洞信息、重大安全事件、网安新闻资讯、网安赛事资讯、其他资讯 |
| **规则分类** | 监管机构预警：公众号+标题规则（Phase 1 已实现） |
| **大模型分类** | 其余类别（Phase 2 待接入） |
| **轮巡实时** | 监管机构预警、重大安全事件 → 北京 **6、18** 整点 + 定时档同跑时推送 |
| **LLM** | 分类、翻译、噪声复核、IOC 提取、英文摘要均用 `qwen-plus`（GitHub Secrets 可覆盖） |
| **英文中文摘要** | 英文稿生成 HTML → 上传 **阿里云 OSS**，企微只附外链（需配置 `OSS_*` Secrets） |
| **知识库** | 历史文章归档 OSS `kb/`；**查阅请用独立应用** [`intel-app/`](../intel-app/)（API+Web，与推送解耦）。`kb/search.html` 仅作备份 |
| **每日要点 PDF** | 北京 18:00 轮巡后生成；**只含当天企微已推送过的条目**，企微只推一份 PDF |
| **定时推送** | 定时六类 → 北京 **9:30、12:00、15:30、17:30**；**漏洞**仅推金融常用组件或大规模/高危（其余入库不发企微） |
| **推送格式** | 【信息类型】【标题】【时间】【链接】 |
| **去重** | 链接去重 + **跨源同事件**标题相似度去重（`story_dedup`） |
| **噪声过滤** | 规则剔除 + 校园赛事屏蔽 + 公众号语义复核；见 `exclusion_reason` |
| **重大事件口径** | 仅「超大影响/跨国」或「金融·类金融」网安实害，其余降为网安新闻 |
| **监管预警 @** | 推送「监管机构预警」时 @ `wangxuyang`、`qinxiaoxia`（企微 userid，可改 Secret） |

## 文件说明

| 文件 | 说明 |
|------|------|
| `main.py` | 主程序 |
| `classifier.py` | 分类器（规则 + 大模型占位） |
| `config.py` | 配置（需自行创建） |
| `config.example.py` | 配置示例 |
| `rss_push.db` | 文章与推送记录（自动生成） |

## 运行

```bash
pip3 install -r requirements.txt
python3 main.py
```
