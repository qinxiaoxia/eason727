VMware vCenter Server 高危漏洞可未授权创建管理员

时间：2026-11-24 18:12
来源：微步在线研究响应中心公众号
原文：https://mp.weixin.qq.com/s/jkjqyaXmwlAi2LBNhnoAeA

中文摘要

VMware vCenter Server 被曝出一个高危未授权漏洞（微步编号XVE-2026-62902，CVE编号CVE-2026-123903），风险等级为高，分数9.8。该漏洞由微步XGPT发现并报送VMware官方。攻击者无需任何权限即可利用此漏洞，通过访问vCenter内置的vmdir目录服务所使用的389端口，在特定认证流程中绕过身份验证，创建管理员账号并完全接管vCenter服务器。该漏洞与近期发布的CVE-2026-123890不同。受影响版本包括vCenter Server 7.x、8.0U3m以下版本、9.0.x.x至9.0.2.0300及9.1.x.x至9.1.2；同时影响VMware Cloud Foundation和Telco相关平台的多个版本。目前已有修复补丁发布，建议所有受影响用户立即更新。

要点

  • 漏洞类型：身份鉴别错误
  • 利用条件：可远程、无需权限、无需受害者配合、无需绕过安全机制
  • 影响产品：VMware vCenter Server及其关联产品
  • 风险等级：高（CVSS评分9.8）
  • 已提供修复补丁，需尽快升级
